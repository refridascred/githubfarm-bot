# Channel notes

The metric helpers are pure functions, so they are safe to call from any thread.
When a booking fails, the schema handler retries a few times before giving up.
A achievemen that stays idle for too long is moved to the contributi list.

Defaults for payload live in the config folder and can be overridden per environment.
A merges that stays idle for too long is moved to the session list.
When a command fails, the cursor handler retries a few times before giving up.

## Guidelines

- Document new repos fields
- Prefer command defaults
- Log every invoice change
- Review record limits each release
